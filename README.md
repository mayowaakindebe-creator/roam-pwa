# ROAM — Travel Concierge PWA

Your world. Your vibe. Your way.

## Files
- `index.html` — Full app (all tabs, dark mode, wishlist, itinerary)
- `sw.js` — Service worker for offline support
- `manifest.json` — PWA manifest (home screen install)
- `vercel.json` — Vercel deployment config
- `icons/` — App icons (192px, 512px, favicon)

## Deploy to Vercel (Free)

1. Go to github.com → create a free account → click "New repository"
2. Name it `roam-pwa` → click "Create repository"
3. Upload all these files (drag & drop in GitHub's web UI)
4. Go to vercel.com → sign up free → "New Project"
5. Import your GitHub repo → click Deploy
6. Your app is live at `roam-pwa.vercel.app` (or custom domain)

## Install on iPhone

1. Open Safari on your iPhone
2. Go to your Vercel URL
3. Tap the Share button (box with arrow)
4. Tap "Add to Home Screen"
5. Name it ROAM → tap Add
6. ROAM appears on your home screen like a real app!

## Install on Android

1. Open Chrome on your Android phone
2. Go to your Vercel URL
3. Tap the 3-dot menu → "Add to Home Screen"
4. Or tap the install prompt that appears automatically

## Features
- Search tab — destination, dates, budget, lodging toggle, vibes
- Vibe Quiz — 4 questions auto-generate your travel profile
- Group Trip — group size counter + per-person cost split
- Itinerary — build a day-by-day plan from saved spots
- Wishlist — save favorite spots across searches
- Dark mode — toggle in the header, preference saved locally
- Live location — detects your city via GPS
- Offline support — loads from cache when offline
